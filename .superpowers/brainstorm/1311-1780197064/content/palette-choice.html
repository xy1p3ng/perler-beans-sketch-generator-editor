色卡数据策略

色卡是拼豆工具的核心资产。MVP 阶段你倾向于哪种方案？

方案对比

A

只用 MARD 色号（参考项目同款）

参考项目已内置完整的 MARD 色号对应表（约 200+ 色），可直接复用。MARD 是国内拼豆玩家最常用的色号体系。

优点

  • 数据现成，无需整理
  • 参考项目逻辑可直接复用
  • MARD 是国内主流

缺点

  • 不支持 Perler/Hama/Artkal
  • 商家可能需要其他品牌
B

MARD 为主 + 支持自定义导入色卡

内置 MARD 作为默认色卡，同时提供色卡导入/编辑功能，用户可自行添加 Perler、Hama 等品牌数据。

优点

  • 保留 MARD 开箱即用
  • 支持任意品牌扩展
  • 符合 PRD 的色卡管理设计

缺点

  • 需要开发色卡导入/编辑 UI
  • 增加 MVP 开发量
C

内置多品牌（MARD + Perler + Hama）

MVP 就整理并内置多个主流品牌的色卡数据，用户可在生成时切换品牌。

优点

  • 品牌切换体验完整
  • 直接对标竞品（Perlypop 等）

缺点

  • 需要收集/验证多品牌色卡数据
  • 色差计算需考虑品牌间差异
  • 显著增加 MVP 工作量

💡 我的建议：选 B。MARD 覆盖国内主流需求，自定义导入给进阶玩家和商家留出扩展空间，工作量增加可控。
