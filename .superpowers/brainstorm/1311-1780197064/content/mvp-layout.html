关键决策：技术栈选择

参考项目使用 Next.js + React + TypeScript + Tailwind CSS。你的偏好是？

A

Next.js + React + TS + Tailwind（参考项目同款）

与参考项目技术栈一致，组件和逻辑可高度借鉴。适合 SSR/SEO，有 PWA 支持。

B

Vite + React + TS + Tailwind

更轻量，启动更快，没有 Next.js 的框架约束。纯前端 SPA 足够。

C

Vue 3 + Vite + TS + Tailwind

如果你更熟悉 Vue 生态，状态管理和组件写法会更顺手。
